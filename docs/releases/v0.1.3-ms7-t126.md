## Purpose

Correct the package-facing workflow after the v0.1.2 single-class baseline. The v0.1.2 interface still read like a function bundle behind one class and its README ran tests/queries before showing LLM registration. This release makes the recommended API stepwise and provider-first.

## Public Workflow

```python
from pxfquery import PxFQuery

pxf = PxFQuery()
pxf.settings.register_llm(...)
q = pxf.read.query("Which drugs activate apoptosis in A549 cells?")
pxf.pp.parse(q)
pxf.tl.resolve(q)
result = pxf.get.result(q)
```
