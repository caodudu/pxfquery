# PxFquery v0.1.2

- CyHex task: `T-125 task_ms7_public_api_single_class_v012`
- Git tag: `v0.1.2`
- Change direction: public API contraction to one class

## Scope

This version changes the user-facing interface shape only:

- `from pxfquery import PxFQuery` is the intended public import.
- `pxfquery.__all__` is `["PxFQuery"]`.
- Provider registration and inspection are documented as `PxFQuery` methods.
- README no longer recommends top-level function imports.

This version does not change parser semantics, route semantics, corpus content,
or engine behavior.
