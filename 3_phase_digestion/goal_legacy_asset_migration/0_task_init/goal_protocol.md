# Goal Protocol

This goal handles protocol digestion and legacy asset understanding before any substantial development resumes.

Step 1 is detailed digestion of the original assets and protocol evolution.
Step 2 is a dedicated migration planning task after the asset picture is clear.

Outputs should clarify:

- which old directories are authoritative for code, reports, and submission strategy
- which assets should remain linked only
- which assets should later be copied or re-executed inside this project
