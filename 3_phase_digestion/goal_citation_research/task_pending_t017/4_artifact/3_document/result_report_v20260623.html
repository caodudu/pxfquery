MDPI / Genes 期刊在 Zotero 中的引用格式为：

Multidisciplinary Digital Publishing Institute

编号制引用格式：文中使用 [1], [2], [3] 编号引用

✓ Zotero 官方仓库标准样式，可直接安装

在 Zotero 中如何安装

  1. 打开 Zotero 桌面应用
  2. 点击 Edit → Preferences（macOS：Zotero → Preferences）
  3. 选择 Cite 选项卡
  4. 在 Style Manager 下点击 Get additional styles...
  5. 搜索 "Multidisciplinary Digital Publishing Institute"
  6. 点击该样式，然后点击 Install

引用格式示例（从MDPI官方指南）

期刊论文：
Malik, V.S.; Schulze, M.B.; Hu, F.B. Intake of sugar-sweetened beverages and weight gain: A systematic review. Am. J. Clin. Nutr. 2006, 84, 274–288.
