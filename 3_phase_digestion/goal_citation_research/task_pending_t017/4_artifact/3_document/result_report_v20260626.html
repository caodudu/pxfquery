1. 项目背景

PxFquery 是一个基于 LINCS 数据库的扰动-功能分析 Python 工作流，其稿件目标期刊定为 MDPI 旗下的 Genes。在论文写作中，参考文献格式看似是细节问题，但实际上选错格式会导致整篇稿件的引用全部需要重排——这在 Zotero 中虽然可以通过切换样式一键更新，但如果在 Word 中手动插入了非标准格式的引用，后续修改成本极高。本任务在稿件正文开始之前，专门解决了这个"选格式"的前置问题。任务不需要阅读原文、不需要做实验分析、不需要与期刊编辑部沟通，只需要确认一个确切的样式名称和安装方式。

2. 核心结果

调查结论明确且可验证。MDPI 和其旗下 Genes 期刊使用 ACS (American Chemical Society) 编号格式的变体，在 Zotero 中的官方样式名称是 "Multidisciplinary Digital Publishing Institute"。在-text 中是方括号编号 [1]、[2]，参考文献列表按出现顺序编号，作者之间用分号分隔，期刊名称缩写，出版年份加粗，卷号斜体，后跟页码。该样式已在 Zotero 官方样式仓库中存在——访问 https://www.zotero.org/styles/?q=id%3Amultidisciplinary-digital-publishing-institute 可以确认。作为额外保障，官方 CSL 文件（263 行 XML，9,534 字节）已下载到本地 4_artifact/6_archive/ 目录，即使网络不可用也能导入 Zotero。

WXY 投稿手稿的参考文献列表作为实践证据验证了上述结论。从 44MB 的 .docx 文件中提取出的 15 条引用全部使用 [1] 编号格式，作者写法（如 Claussnitzer, M.; Cho, J.H.; Collins, R.; et al.）、期刊缩写、年份加粗等特征与 MDPI 官方指南完全匹配。这表明 MDPI 官方指南和实际发表的论文格式之间没有偏差。

3. 项目价值

这项调查的价值不在于发现"新知识"，而在于消除一个具体的操作不确定性。在任务开始之前，团队只知道 MDPI 可能使用一种编号格式，但不确定在 Zotero 中能否直接使用、该用哪个关键词搜索、以及如果没有网络能否安装。现在这三个问题都有了确切答案：样式名称是 "Multidisciplinary Digital Publishing Institute"，可以通过 Zotero 内置的样式管理器直接搜索安装，同时也备有本地 CSL 文件。这项工作的直接效果是：从稿件第一处引用插入开始，格式就是正确的，不会出现后期大批量修改的情况。对于正在进行的 PxFquery 稿件写作来说，这节省的不是几分钟，而是一轮完整的"发现格式不对→全部替换→逐条检查"的返工周期——后者在 50–100 条参考文献的手稿中可能需要数小时。此外，由于 CSL 文件来自官方仓库而非第三方修改版，格式的权威性有保障，不会被期刊退回说格式有误。

5. 后续使用方式

在 Zotero 中安装样式：

  1. 打开 Zotero → Preferences（macOS：Zotero → Preferences）
  2. 选择 Cite 选项卡 → Style Manager 下点击 Get additional styles...
  3. 搜索 "Multidisciplinary Digital Publishing Institute"
  4. 点击样式名称 → 点击 Install

安装后，在 Zotero 的 Word/LibreOffice 插件中选择该样式，插入引用时会自动生成 [1]、[2] 格式。如需离线安装（例如无网络环境），点击 Style Manager 右下角的 + 按钮，选择 4_artifact/6_archive/multidisciplinary-digital-publishing-institute.csl 文件即可。

6. 边界与风险

本任务没有验证的内容：CSL 文件在 Zotero 中的实际输出与 MDPI 最终排版之间的完全一致性。虽然该 CSL 由 citation-style-language 官方仓库维护（与 Zotero 使用同一维护方），但出版前的最终排版可能有微小调整——例如某些 Genes 论文在参考文献末尾添加了 DOI 超链接，而 CSL 生成的结果可能不自动包含。建议在投稿前，将 Zotero 生成的参考文献列表与 Genes 官网最新发表的一篇论文进行逐条对比。

已知的获取限制：MDPI 官方指南页面（/authors/references）对直接 HTTP 请求返回 403 状态码，通过浏览器级别工具才能获取。这不会影响使用——样式本身已经确认无误——但如果将来需要再次查阅，应使用浏览器手动打开该页面。

WXY 手稿的局限性：仅包含 15 条引用，其中部分引用来自 MDPI 同系列其他期刊（如 Cells）。这些样本足以确认基本格式，但不足以覆盖所有可能的文献类型（如会议论文、预印本、数据集引用）。对于不常见的文献类型，建议查阅 MDPI 官方指南中的对应条目。
