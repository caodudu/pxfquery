# Development asset digestion

This digestion goal is about PxFquery development assets, not legacy migration.

It should answer:

- what PxFquery was intended to become as a tool/workflow;
- what code, data loaders, query/index components, reports, and validation evidence already exist;
- which parts are usable, unfinished, obsolete, or only historical;
- what should be handed off to a later development phase.

Tasks under this goal should not refactor code or run full development work. They prepare the development phase by clarifying current technical state and source authority.
