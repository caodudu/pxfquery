一句话总结

本任务拆解了 5 篇 Genes 已发表生信论文的介绍/结果/图摆放逻辑，归纳出 Genes 风格可模仿模式。这些拆解可作为 PxFquery 后续论文写作的模板参考——重点是让论文看起来"像 Genes 接受的样子"，而不是追求 Nature 标准。

核心发现

维度Genes 典型模式对 PxFquery 的意义
题名工具名: 功能 + 应用场景给 PxFquery 取一个可记忆的名 + 固定格式
Intro具体生物学痛点 → Gap（已有方法不足）→ "to address, we..."不要空谈 AI/big data，锚定 perturbation→function 的具体场景
Results短段落(38-44词/段)密集推进，每段配图表引用30-80段Results：从内部对比到外部验证再到案例
图4-6图。图1=架构图。后续按验证深度排列架构图 + 性能表 + 案例图 + availability 表 最少组合
交付描述用户输入→系统处理→用户输出→验证固定描述框架，不要含糊
弱点Discussion 中主动承认样本量/外部验证/代码开放等可以在讨论中说明
