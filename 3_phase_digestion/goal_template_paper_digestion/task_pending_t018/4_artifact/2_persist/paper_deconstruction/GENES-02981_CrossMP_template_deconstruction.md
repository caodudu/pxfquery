**题名:** Enabling Cross-Modality Translation between Single-Cell RNA-Seq and Single-Cell ATAC-Seq through Web-Based Portal

**结构指标（据 T012）：** 当前无本地全文结构统计（missing_full_text），以 metadata/abstract 级别证据 + portal 型论文通用模式分析

---

## 一、介绍写作逻辑

### 问题锚定方式
从"单细胞多组学整合"这个热门领域切入。起手就抓住"把 scRNA-seq 和 scATAC-seq 结合起来"这个需求——这是单细胞领域公认的分析难题。

### Gap 构建链条
1. 先说明多组学 profiling 的趋势（"growing interest in profiling multiomic modalities"）。
2. 指出整合 scRNA-seq + scATAC-seq 对更准确的预测和全面理解有好处。
3. 暗示现有方法要么缺少跨模态翻译能力，要么缺少易用的 web 入口。
4. 提出自己的解决方案：CrossMP，一个 web-based portal。

### Genes 典型套路
- 选题踩在热门前沿上（单细胞+多组学），但切入点具体（就是 translation + portal）。
- Gap 不追求技术创新缺口，而是追求"可及性缺口"：别人没有把跨模态翻译做成 web tool，我来做。

## 二、结果写作逻辑

### 预期段落结构（据 portal 型论文通用模式）
1. **系统架构段**: 展示 portal 的整体架构、支持的数据格式和模态。
2. **数据上传/输入段**: 用户如何提交单细胞数据。
3. **翻译结果段**: 跨模态翻译的核心效果展示。
4. **可视化段**: 交互式可视化界面截图和功能说明。
5. **验证/案例段**: 用一个或两个公共数据集演示 portal 的有效性。

### 段落间推进方式
- "你上传什么 → 系统怎么处理 → 你看到什么 → 结果可不可信"的顺序推进。
- Portal 型论文天然适合截图驱动叙事。

### 结果包装策略
- Portal 文章的核心是"让人感觉能用"：截图、用户流程、输出界面是主力证据。
- 工作量的感知来自：系统复杂度 + 可视化丰富度 + 案例数量。

## 四、可模仿要点

1. **选题切入**: 在热门领域找一个"缺工具"的具体缺口——不是缺方法，是缺易用入口。
2. **Portal 包装**: 架构图+界面截图+案例演示是最小的"看起来像工具"组合。
3. **结果叙事**: 以用户旅程（上传→处理→查看→验证）为线索组织段落。
4. **注意**: 需要确认 portal 是否真的能访问（T012 标记为需要后续重点核对），不要学习"声称有 portal 但实际不可用"的写法。
