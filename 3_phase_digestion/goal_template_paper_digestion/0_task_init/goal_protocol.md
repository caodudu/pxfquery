# Goal Protocol

This goal handles digestion of specific template papers and their supporting submission materials.

The purpose is to understand how an already-submitted or accepted paper is built from the inside: manuscript logic, scientific question, evidence structure, methods, figures, supplementary materials, source data, cover letter framing, and submission package organization.

Tasks under this goal should first explain the template paper on its own terms. Any connection to PxFquery should come only after the template paper has been digested, and should be framed as lessons, reusable patterns, cautions, or possible inspiration. These tasks should not repeatedly compare the template paper with PxFquery during primary reading.

Expected outputs include structured reading notes, figure/table maps, evidence maps, writing-pattern summaries, and a Chinese HTML report suitable for later manuscript planning.
