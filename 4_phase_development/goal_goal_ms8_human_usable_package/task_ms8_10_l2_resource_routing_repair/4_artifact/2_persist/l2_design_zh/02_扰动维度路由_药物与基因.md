# 02 扰动维度路由：药物与基因

日期：2026-06-28

## 这个维度解决什么

扰动维度比普通名字匹配复杂。用户可能说药物商品名、通用名、靶点类别、BRD ID、基因符号、基因功能、敲低、过表达、抑制、激活。资源里却通常按具体药物 ID、基因符号、扰动方式和矩阵可用性组织。

因此 L2 要判断三件事：

```text
扰动对象是谁
扰动方式是什么
资源里有没有这个对象和方式
```

如果 exact perturbation 不存在，L2 才能按受控近邻找代理，不能直接凭语言相似度造结果。

## 药物路由的 T007 源码资料来源

这部分有 T007 源码依据：

- `Migrated PxFquery package code/index/drug_index.py`
- `Migrated index builder and resolver scripts/M-0365_build_drug_index.py`
- `Migrated PxFquery package code/llm/prompts.py`
- `Migrated PxFquery package code/query/resolver.py`

T007 源码提供的药物资料包括：

- alias 到 BRD ID 的映射。
- LLM 归一化候选后，再用 drug index 校验。
- `drug_neighbors.json` 里的结构近邻。
- builder 中基于 PubChem、Morgan fingerprint、Tanimoto 相似度构建近邻。

## 药物路由原理

药物路由应先尝试 exact alias/BRD 命中。用户说的名字如果能通过 alias 解析到资源中的 BRD ID，就标为 exact perturbation。

如果用户表达不是明确药物名，例如“EGFR inhibitor”，LLM 可以提出候选药物名。但 LLM 结果只能是候选，必须经过 drug index 验证。没有通过索引验证的药物不能成为证据 route。

如果 exact drug 存在但目标细胞里没有 pair 数据，L2 可以展开结构近邻。结构近邻的来源必须是 T007 builder 生成的 Tanimoto neighbors，而不是临时字符串相似度。

## 基因路由的 T007 源码资料来源

这部分有 T007 源码依据：

- `Migrated PxFquery package code/index/gene_index.py`
- `Migrated index builder and resolver scripts/M-0367_build_gene_index.py`
- `Migrated PxFquery package code/llm/prompts.py`
- `Migrated PxFquery package code/query/resolver.py`

T007 源码提供的基因资料包括：

- gene symbol 规范化。
- gene type。
- `in_matrix` 可用性。
- xpr/sh 等矩阵可用性信息。
- GenePT semantic embedding 近邻。
- cosine 相似度压缩存储的 gene neighbors。

## 基因路由原理

基因路由应先把用户输入转成规范 gene symbol，并验证是否在资源索引里。用户说 “TP53” 和 “p53” 这类表达，不能只靠字符串原样传下去。

如果 exact gene 不在矩阵中，但索引有语义近邻，L2 可以展开 GenePT neighbors 作为代理候选。这个代理的含义是“功能/语义相近基因”，不是同一个基因，证据等级必须低于 exact gene。

基因还必须带扰动方式。`overexpression`、`knockdown`、`knockout`、`inhibition` 不是同一种证据。L2 应该根据资源实际支持的 xpr/sh 等 modality 决定可执行路线，不能只输出一个 gene name。

## T007 没有完整给出的部分

T007 有 xpr/sh 可用性和 gene neighbors，但没有把基因扰动方式整理成完整 ontology。比如 RNAi、shRNA、CRISPR knockout、overexpression、loss-of-function、gain-of-function、mutation-only context 之间的关系，T007 源码没有给出完整规则。

因此 T138 不能假装已有完整 modality routing。需要明确补一个扰动方式层，并且每个方式必须能落到资源支持的 engine 或返回 unresolved。

## L2 输出应该长什么样

扰动路由输出至少要能表达：

- 原始扰动表达。
- 规范化对象：BRD ID 或 gene symbol。
- 扰动类别：drug、gene、compound class、target class 等。
- 扰动方式：drug treatment、xpr、sh、其他资源支持方式。
- exact/proxy 等级。
- 近邻来源：alias、Tanimoto neighbor、GenePT neighbor。
- 是否在目标细胞和目标 engine 中有 pair availability。
