T-028 功能索引包构建执行报告

生成日期：2026-06-26 | 任务标识：T-028 function_index_pack_v1

1. 任务意图

PxFquery 项目依赖三套扰动-功能矩阵（cp_func_ad、sh_func_ad、xpr_func_ad），每套矩阵的列（var）对应 91 个 MSigDB Hallmark 基因集功能术语。下游的查询解析器（resolver）需要一份可信的功能术语索引，才能将用户输入的查询词匹配到矩阵列名，进而检索功能评分。T-028 的任务就是构建这份索引：从真实 H5AD 文件中读取那 91 个术语，为每个术语配备别名列表（包含自身全大写、全小写、可读标签三种形式），打包为版本化的 function_index.json，并通过自动化验证脚本证明索引与原始矩阵完全一致。这一工作的直接原因是 T-013 任务发现上游迁移而来的 function_index.json 存在缺失或不完整的问题，T-028 需要在原地构建一份经过验证的本地替代品。

2. 输入资产与依据

任务使用了八类上游资产。矩阵数据来自 T-021 标准资源包（D-004）中的三个 H5AD 文件，通过 T-026 加载器（D-001）的 load_matrix 接口读取 var_names。上游的 function_index.json 经由 T-027 运行时查询索引包（D-001）解析路径后读取，作为别名种子来源。T-013 的能力合约（D-001）和失败记录（D-005）提供了任务启动的缺口证据。T-026 加载器的验证记录（D-003）提前确认了 91 行 n_var 信息，T-027 的模式报告（D-002）描述了上游 JSON 的顶层结构。T-013 的审查报告（D-006）提供了功能索引缺口的中文上下文。所有上游资产均为只读引用，T-028 未做任何修改。

3. 实际执行过程

任务分为六个步骤。第一步，使用 T-026 加载器依次读取三个 H5AD 矩阵的 var_names，确认三者长度均为 91 且列表完全一致，将观察结果写入 3_execution/01_verify/01_var_names.json。第二步，解析 T-027 提供的 symlink 路径，找到上游 function_index.json，以 json.load 读取并检查顶层键（var_names、aliases、meta 均存在），将检查记录写入 3_execution/02_inspect/02_upstream_function_index.json。上游文件存在且格式完整，其 aliases 映射被作为别名种子使用。第三步，构造 4_artifact/2_persist/pxfquery_T028_function_index/function_index.json，包含 version 标识、matrix_source、loader_source、91 个 var_names、每个术语的别名列表（自身大写 + 小写 + 可读标签共 273 条目）、以及记录上游状态和构建日期的 meta 信息。第四步，生成 91 行每术语一行验证表 4_artifact/5_table/pxfquery_t028_function_index_validation.csv。第五步，运行 validate_function_index.py 执行 7 项结构化检查，全部通过。第六步，撰写中英文下游使用说明文档。

4. 关键判断与证据

第一个关键判断是功能术语的权威来源必须为运行时 H5AD 文件，而非任何计划文本或上游 JSON。T-026 加载器逐矩阵读取 var_names 并交叉验证三者一致性，确保索引术语来自"正在使用的数据"而不是"曾经有人写过的东西"。第二个判断是当上游 function_index.json 存在且完整时，应将其别名作为种子而非完全取代——T-013 标记的缺失问题针对的是已迁移的旧目录，并非 T-021 标准资源包当前提供的文件。上游 JSON 提供的是小写到大写的 1:1 映射，T-028 将其扩展为每术语包含三个别名的列表格式，增加了可读标签以便下游直接使用。第三个判断是别名构建不得自行猜测或捏造，缺失的上游别名记录为空列表并在验证表中标记。验证结果显示 7/7 全部通过，三矩阵 var_names 完全一致，91 个术语的别名全部非空且第一项为自身。证据文件分布在 3_execution/ 和 4_artifact/ 子目录中，均可独立复现。

6. 边界与未完成事项

T-028 是一个索引构建任务，不是查询引擎、解析器或软件包里程碑。交付物不包含任何运行时服务、API 端点、LLM 集成或用户界面。别名目前仅为三种形式（UPPER、lower、Label），不涵盖同义词、跨本体映射或手动精选别名集——这些属于下游 resolver 任务的处理范围。任务未修改任何上游 T-021、T-026、T-027 或 T-013 资产。验证脚本需要在 pxfquery conda 环境中运行，复现命令为 conda run -n pxfquery python 3_execution/validate_function_index.py。如果后续矩阵定义发生变化（术语增删或顺序调整），T-028 索引包需要对应重建。
