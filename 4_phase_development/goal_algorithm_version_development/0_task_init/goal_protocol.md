# Algorithm version development — Protocol

This development goal is for algorithm code changes after review evidence exists.

Tasks under this goal should be opened only when G-005 has produced a concrete failing test, missing capability, or version target. Each development task should name the review evidence it addresses, define the intended behavior, implement the smallest useful fix or feature, and rerun the relevant tests.

This goal should not absorb broad exploratory review work. Broad uncertainty belongs in G-005; confirmed repair, implementation, and version packaging belongs here.
