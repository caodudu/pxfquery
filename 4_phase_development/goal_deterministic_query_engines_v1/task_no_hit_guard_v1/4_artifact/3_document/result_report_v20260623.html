pxfquery-T-031 No-hit guard 结果报告

生成: 2026-06-23 | Guard 版本: pxfquery-T-031

问题背景

PxFquery 的 fuzzy_match 函数有一个危险的 token-overlap 回退：任何 token 重叠（overlap > 0）均视为匹配。 这导致无意义短 token（如 egr、bra、akt）或包含单个共享 token 的名字（如 egfr_random）被错误匹配到真实基因， 进而导致正向查询产生假阳性结果。

T-013 CAP-05 原始状态: 失败
原因: "当前 fuzzy fallback 对无意义扰动名仍会给出相近 token，存在误报风险"
修复任务: T-031 no_hit_guard_v1

守卫实现

参数默认值作用
min_query_length_for_substring 4 子串匹配查询的最短长度。阻止如 egr（3 字符）误匹配 EGR1 的情况
min_overlap_for_token_fallback 2 token-overlap 回退时要求的最小共享 token 数。阻止如 egfr_random（只共享 egfr 一个 token）误匹配 EGFR

守卫通过继承 ForwardQuery 并覆盖 query() 方法实现。不修改 T-024 workspace 中的任何文件。
