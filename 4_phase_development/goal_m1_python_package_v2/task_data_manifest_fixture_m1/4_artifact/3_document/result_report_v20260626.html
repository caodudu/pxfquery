T-043 结果报告：M1 数据基板已就绪

1. 一句话结论

T-043 交付了一份完整的 M1 数据资源清单、一个最小真实数据夹具包、结构描述表和样本记录表，为 PxFquery 下游六个开发任务提供了稳定、可追溯且不依赖原始资产的数据边界。

2. 项目背景

PxFquery 是一个基于 LINCS 扰动数据的基因功能程序查询工具。项目经过多次重启后，当前阶段的目标是构建一个干净的 Python 包，避免直接依赖 Windows 时期的遗留目录树。为了实现这一目标，必须先定义一个"M1"级别的权威数据基板——列出可用的标准资源及其路径，并提供一份足够小的真实数据切片，使加载器和查询代码能在真实数据上进行开发调试，而无需加载数十万行的大矩阵。T-043 正是在这一节点上执行的基础数据准备任务。

3. 核心结果

资源清单 resource_manifest_m1.yaml 收录了 36 个资源条目，涵盖 18 个完整标准资源（3 个 H5AD 矩阵、2 个细胞元数据 CSV、2 个化合物元数据 CSV、1 个基因信息 CSV、10 个查询索引 JSON）和对应的 18 个夹具资源。结构描述表 expected_shapes_keys_columns_m1.csv 明确了每个资源的形状、键字段、必需列和索引语义。夹具包仅占极小的磁盘空间：cp 矩阵 4×7、sh 矩阵 4×7、xpr 矩阵 4×7，4 种细胞系的元数据行和 8 个基因的信息行全部来自真实分数，分数范围从 -10.0 到 10.0 不等。样本记录表提供了 46 行可追溯的源标识，下游开发人员可直接用这些标识选取 demo 输入。

4. 项目价值

这项任务将原本分散在 T-014 和 T-021 产出中的数据结构知识固化为一个可编程入口点。此后 T-046（加载器）、T-047（硬化资源加载）、T-048（前向查询）和 T-049（反向查询）等任务不必各自翻阅前序文档或扫描原始资产，只需读取 resource_manifest_m1.yaml 和 README 即可获得全部路径与格式信息。夹具包的确定性使得测试结果可重复，不会因为全量矩阵的行顺序或数据变更而产生误报。任务同时也标注了三项已知排除内容（截断的 CMAP H5AD、历史 GSEA 产物、GenePT 嵌入），防止下游误以为全量资源等于所有历史数据。

6. 后续使用方式

T-046 应优先读取资源清单，然后针对夹具资源实现最小加载器。T-048 和 T-049 可使用样本记录表中的扰动签名标识作为 demo 输入，例如 cp:ABY001_A375_XH:BRD-K66175015:10:24 用于前向查询演示。当需要全量搜索行为时，任务代码应回退到完整的标准资源路径。夹具不用于生物学排名性能声明，仅验证代码接线正确性。

7. 边界与风险

夹具包仅含每类矩阵 4 条观测和 7 个功能变量，无法代表完整 91 变量的生物多样性。如果下游任务需要高排名保真度或全谱功能覆盖，必须切换到完整标准资源。任务未使用任何 LLM、合成数据或外部网络资源，所有记录均来自 T-021 的可验证标准资源包。未修改前序任务产出或项目协议状态。
