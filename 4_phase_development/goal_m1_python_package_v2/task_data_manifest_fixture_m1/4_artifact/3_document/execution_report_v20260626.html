T-043 执行报告：数据清单与测试夹具构建

1. 任务意图

PxFquery 项目需要一个稳定且可重复的 M1 数据基板，使下游的加载器、前向查询、反向查询和包组装任务有一个可靠的数据边界，不必反复读取大量项目原始资产或遗留代码目录。T-043 的任务就是在不发明数据、不依赖失败上游产出的前提下，从已有权威资产中整理出一份资源清单、一个最小真实数据夹具包以及对应的结构描述表。这项工作是整个 goal_m1_python_package_v2 开发的底层数据垫层，后续所有加载与查询代码都将以此处定义的路径和内容为起点。

2. 输入资产与依据

执行严格按照协议要求，仅读取 T-014 和 T-021 注册的六个资产（A-001 至 A-006）。A-001 提供了 T-021 产出的标准资源包，包含化合物（cp）、shRNA（sh）和过表达（xpr）三类功能性 H5AD 矩阵及其元数据 CSV 文件和查询索引 JSON 文件。A-002 是标准资源格式决策文档，A-003 是验证过程记录，A-004 至 A-006 来自 T-014，帮助划定数据范围、资源清单和矩阵模式覆盖。没有访问任何 2_project_asset 原始数据、T-024 至 T-040 的失败产出或网络下载数据。

3. 实际执行过程

执行的第一步是读取 A-001 标准资源包的全部文件，确认其目录结构、文件类型和实际行数。随后从三类 H5AD 矩阵中各选出 4 条真实扰动签名观测，并选取 7 个功能变量列（5 个 Hallmark 通路和 2 个 MP 模块）组成夹具矩阵，使夹具形状统一为 4×7。元数据 CSV 和查询索引 JSON 的夹具行则按照所选观测进行有界提取：选中 A375、BICR6、PC3、U251MG 四种细胞系；选中 afatinib、erlotinib、HMN-214、neratinib 四种化合物；选中 A2M、AATF、ABAT、ABCA1、CPVL、ORAI3、SLC19A3、STAC 八个基因。所有提取操作都是有界子集截取，不含任何合成或派生分数。

产出物共 8 项：资源清单 YAML 标注了 36 个资源（18 个完整标准资源 + 18 个夹具资源），最小夹具包包含 3 个 H5AD 文件、5 个 CSV 文件和 10 个 JSON 文件，结构描述表涵盖所有资源，样本记录表列出 46 条可追溯行。验证环节重新加载了所有 H5AD 和 CSV 文件，确认文件可读、形状符合预期、分数范围合理。

4. 关键判断与证据

选择 7 个功能变量而非覆盖全部 91 个，是为了保持夹具小型化和确定性，同时覆盖 Hallmark 和 MP 两类函数来源。细胞系的选择涵盖了皮肤、前列腺、上呼吸道和中枢神经系统四个谱系，使细胞系邻居索引和树索引在夹具中具有代表性。化合物全选 EGFR 抑制剂家族，便于下游演示同类药物的功能对比。所有夹具记录的分数值均直接复制自 A-001 标准矩阵，例如 afatinib 在 A375 细胞上的 E2F_TARGETS 分数为 -10.0，erlotinib 的 TNFA_SIGNALING 分数为 4.366983。验证日志 3_execution/validation_log_m1.json 记录了每项检查的通过状态。

夹具包的规模是刻意缩小的，仅用于测试加载器接线和查询方法演示，不足以替代完整标准资源的生物学排序验证。上游 T-021 报告的截断 CMAP H5AD 文件、历史 GSEA 产物和 GenePT 嵌入均被排除在外。任务没有修改任何前序任务的产出或项目协议状态。后续 T-046 加载器任务应首先读取资源清单，再决定使用完整标准资源还是夹具资源。
