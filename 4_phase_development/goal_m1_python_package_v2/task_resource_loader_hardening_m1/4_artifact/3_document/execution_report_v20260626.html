T-047 resource_loader_hardening_m1 — 执行报告

重写日期：2026-06-26 | 版本：v20260626

1. 任务意图

T-047 是 M1 Python 包（goal_m1_python_package_v2 / G-005）开发阶段中的一次加固与复用资产任务。其核心目标是让 Python 资源加载器能够可靠地处理两类数据来源：完整的标准资源包（t021_standard_resources_bundle，包含真实 h5ad 矩阵、CSV 元数据表和 JSON 索引）和由 T-043 定义的夹具包（fixture_package_m1，18 个文件的轻量确定性子集）。加载器需要解决 T-045 索引健康检查中发现的非标准结构问题——例如 function_index.json 的三段式字典结构、gene_index.json 中 symbol 字段替代 canonical gene_symbol 的命名差异，以及 cellline_tree.json 的扁平而非层级结构。该任务明确要求不得因真实资源不完整而阻塞 M1 的夹具路径，因此在设计上两条路径独立运作。

2. 输入资产与依据

执行依赖八个核心输入资产，全部来自前序或并行任务。A-001（resource_manifest_m1.yaml，来自 T-043）定义了每条资源的预期路径、类型、形状和验证规则，是整个加载器的入口契约。A-002 和 A-003（expected_shapes_keys_columns_m1.csv、sample_records_m1.csv）提供了可量化的验收标准。A-004 至 A-006（index_health_summary.json、index_health_report.md、gap_notes.md，来自 T-045）给出了各 JSON 索引的模式状态、字段缺失和补丁建议，是加载器做字段标准化和解包处理的直接依据。A-007（fixture_package_m1，来自 T-043）是物理夹具包，共 18 个文件，覆盖矩阵、CSV 和 JSON 三种类型。A-008（data_manifest_fixture_m1_readme.md）提供了下游使用的排除说明。T-041 遗留源摘要被明确排除，不参与本次执行。

3. 实际执行过程

加载器代码（loader_hardening_m1.py）实现了三类资源的通用句柄：h5ad 矩阵通过 anndata 库读取并验证 obs 列（需包含 sig_id、cell_iname、pert_id、pert_dose、pert_time 等七个标准字段）和 var_names 匹配；CSV 元数据通过 pandas 读取并校验行数和必需列；JSON 索引则通过 json 加载后检查顶层键、处理特殊结构。function_index.json 被识别为 dict{meta, var_names, aliases} 非标准结构，加载器从中提取了两级分类信息——Hallmark 通路与 3CA MPS 程序——并建立 category 字段。gene_index.json 的 symbol 字段被重映射为 gene_symbol。cellline_index.json 从单层包裹键 valid_cells 中提取 240 个细胞系名。执行以夹具路径和完整标准路径分别运行，两次扫描共加载 36 条资源，均在 6.74 秒内完成。执行过程中修复了两个 bug：gap 严重级别映射从 warning/cosmetic 统一为 warn/info；obs 列过滤逻辑修正了将 var_names 误匹配为 obs 列的问题。

4. 关键判断与证据

全部 36 条资源加载成功，零缺失零错误，验证了加载器的通用性。三条 h5ad 矩阵的实际形状分别为 201014×91（cp）、189365×91（sh）和 132464×91（xpr），与清单预期一致。CSV 表中 cellline_meta 与 cellline_info 均为 240 行，compound_meta 为 6647 行，compound_info 为 39321 行，gene_info 为 12328 行。夹具矩阵形状为 4 obs × 7 vars，var_names 全部匹配预期集合。六项间隙全部来自 T-045 已知索引健康问题，未发现新的间隙：function_index.json 的非标准结构和分类信息存储在 source 字段而非 category 字段（warning）、gene_index.json 的 symbol 命名问题（warning）、cellline_tree.json 扁平结构（warning）、cellline_index.json 单层包裹（cosmetic）、drug_index.json 缺反向查找（cosmetic）。所有间隙均已通过加载器的标准化处理覆盖，夹具路径也提供了相同的处理路径验证。

6. 边界与未完成事项

本次任务不涉及对权威索引或资源包的写操作——所有加载器行为均只读。六项间隙已知且可管理，不影响 M1 夹具路径的独立使用。完整标准路径依赖于 t021_standard_resources_bundle 在配置根目录下的存在性，如果该包缺失，加载器将自动使用夹具路径降级运行。function_index.json 的解包和 gene_index.json 的字段标准化虽然是显式的，但后续消费代码必须读取标准化后的输出字段名称，不能假定原始文件名。未完成的事项包括：drug_index.json 缺乏 BRD 到别名的反向映射、cellline_tree.json 尚未重建为真正的层级树结构——这些已记录为 cosmetic 或 warning 级别间隙，留待后续任务处理。
