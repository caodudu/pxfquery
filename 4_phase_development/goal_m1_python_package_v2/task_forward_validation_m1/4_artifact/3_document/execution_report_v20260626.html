一、任务意图

本任务隶属于 PxFquery 项目 development 阶段 goal_m1_python_package_v2，任务编号 T-050。其核心目标是对 T-059（即 M1 forward query 核心包，作为 T-048 的同层替代）实施独立验证。验证依据是 T-042 定义的 forward demo 合约：以 EGFR（扰动）、A549（细胞系）、xpr（矩阵类型）为正向命中案例，以虚构扰动 UNKNOWN_GENE_XYZ999 为无命中案例。此任务不得修改被验证方的核心逻辑，所有失败必须记录为验证失败而非静默绕过，以便返回同一层级的修复/重试流程。验证范围为包导入、夹具加载、正向查询、无命中查询、JSON 结构比对、CLI 烟雾测试共计 11 项检查。

二、输入资产与依据

验证所用资产全部来自 T-059 任务的交付目录。A-001 为 4_artifact/1_package/ 下的 pxfquery v0.1.0 包，是本次验证的实施对象。A-002 为 4_artifact/2_persist/forward_repair_fixture_m1_1/ 修复夹具，包含一个合成表达矩阵（5 个观测 × 7 个变量），该夹具由 T-059 构建以弥补原始 T-042 demo 的数据空缺。A-003 为对应的清单文件 forward_repair_manifest_m1_1.yaml，其 provenance_label 标记为 synthetic_repair，表明这是合成修复数据而非原始实验数据。此外，T-059 交付的正向参考证据（A-004）和无命中参考证据（A-005）用于 JSON 结构一致性比对。所有路径均在 T-059 任务目录下，验证脚本通过相对引用定位这些资产。

三、实际执行过程

执行分为六个步骤依次进行。第一步：环境准备，将 pxfquery v0.1.0 安装至 pxfquery conda 环境，确认导入成功，记录包版本为 0.1.0。第二步：夹具加载烟雾测试，使用 pxfquery.data.m1_loader.M1FixtureLoader 加载修复夹具，确认 xpr 矩阵形状为 (5, 7) 与清单一致，加载过程无异常。第三步：正向 demo 执行，对 EGFR/A549/xpr 发起前向查询，返回 JSON 中 found 为 true，perturbation 为 EGFR，cell_line 为 A549，n_obs 为 1，top_activated 包含 4 个数值条目（最高 4.03），top_suppressed 包含 3 个数值条目（最低 -6.68）。第四步：无命中 demo 执行，对 UNKNOWN_GENE_XYZ999/A549 发起查询，返回结构化错误对象 {"error": "PerturbationNotFound", ...}，输出为纯 JSON，无 Python 回溯泄漏。第五步：将正向和无命中输出与 T-059 参考证据进行结构比对，剥离 _evidence 字段后关键键完全一致。第六步：CLI 烟雾测试，通过 pxfquery forward 命令行执行正向查询，确认退出码为 0 且 stdout 为有效 JSON。
