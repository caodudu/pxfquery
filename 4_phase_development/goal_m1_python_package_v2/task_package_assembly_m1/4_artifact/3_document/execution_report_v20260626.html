执行报告 — T-052 package_assembly_m1

报告生成日期：2026-06-26 | 原始执行日期：2026-06-24

1. 任务意图

T-052 package_assembly_m1 是 PxFquery 项目 M1 里程碑中关键的包组装任务。在项目前期，T-044 建立了包骨架与 CLI 入口，T-059 修复了前向查询核心逻辑，T-060 修复了反向查询核心逻辑，但这些模块分散在不同任务目录中，无法作为一个整体被 pip 安装使用。T-052 的核心任务是将这些分散的模块统一组装到 src/pxfquery/ 目录树下，创建可安装的包描述文件 pyproject.toml，连接 CLI 子命令与查询后端，使最终用户能够通过一条 pip install -e . 命令获得完整可用的 pxfquery 包。本任务不涉及任何查询算法的重新实现，其全部工作性质是集成与接线。

2. 输入资产与依据

本任务依据任务协议引用了 14 项输入资产。其中 A-001（T-044 pyproject.toml）提供了基础包名 pxfquery 与 hatchling 构建配置；A-015（T-059 pyproject.toml）提供了 [project.scripts] 入口点配置，使得 pxfquery 成为可直接调用的控制台命令。A-002 和 A-003 分别提供了 CLI 子命令框架和 __main__.py 入口。核心查询逻辑来自 A-004（query/forward.py）和 A-005（query/reverse.py），这两份实现来自 T-059 前向修复包。数据加载器来自 A-006，索引模块来自 A-007，LLM 提示模块来自 A-008，可视化模块来自 A-009。前向演示夹具 A-011 和逆向演示夹具 A-013 分别来自 T-059 和 T-060 的 repair fixture，各自带有 synthetic_repair 来源标签。所有资产均在任务协议中有明确映射，未使用 T-048/T-049 的失败输出或 T024-T040 的阻塞资产。

3. 实际执行过程

原始执行按协议 12 个步骤顺序推进。第一步在 4_artifact/1_package/ 下建立了完整目录结构，含 query、data、index、llm、viz、cli 六个子包。第二步处理了 pyproject.toml，合并 A-015 的脚本入口与 A-001 的构建配置，期间发现 readme 字段引用了不存在的 README_TASK.md，将其修复为 README.md 并创建了 stub 文件。第三步从 T-059 前身资产复制了完整的模块树，包括全部查询实现和工具模块。第四步是核心接线步骤——创建 core.py，将 PxFquery 类的 pert2func() 委托给 query/forward.forward_query()，将此前为 NotImplemented 状态的 func2pert() 委托给 query/reverse.reverse_query()，这是整项任务中最重要的单一变更。第五步至第六步完成了 __init__.py 导出和 CLI 接线。第七步 pip install -e . 一次性成功。第八步至第十步依次执行了导入冒烟测试、前向演示和逆向演示，所有输出均为符合 T-042 契约格式的有效 JSON。所有 9 项验收标准全部通过。

4. 关键判断与证据

执行过程中有两项关键判断。第一是 README.md 引用修复：T-059 的 pyproject.toml 中 readme 字段指向 README_TASK.md，该文件在组装目录中不存在，导致 pip install 失败。执行者选择将引用改为 README.md 并在包目录中创建了最小 README，而非回溯修改前序任务资产——这一决策符合协议"不得修改前序任务工件"的约束。第二是 func2pert() 接线：T-059 交付的 core.py 中 func2pert() 为 NotImplemented，执行者将其正确重定向到 reverse_query() 函数，使逆向 CLI 子命令能够端到端工作。证据方面，导入冒烟测试产生了 smoke_test_v20260624.txt，记录了 import pxfquery、版本号 0.1.0、PxFquery 类导入、CLI --help 输出等。前向演示输出保存为 forward_demo_v20260624.json，显示 EGFR 在 A549 细胞中 "found": true，top_activated 包含 ADIPOGENESIS 4.03 和 APOPTOSIS 2.47，top_suppressed 包含 MP40 PDAC-related -6.68。逆向演示输出保存为 reverse_demo_v20260624.json，显示激活 APOPTOSIS + 抑制 MYC_TARGETS_V1 查询返回 "found": true，top_candidates 首位为 THTPA（similarity 1.0）。
