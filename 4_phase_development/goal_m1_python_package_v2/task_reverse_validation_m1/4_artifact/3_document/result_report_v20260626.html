结果报告：T-051 reverse_validation_m1 — M1 反向查询独立验证

生成日期：2026-06-26

1. 一句话结论

验证通过：M1 反向查询实现（T-060/T-044）在全部 42 项检查中均通过，功能正确性符合 T-042 合同要求。排除已记录的结构性符号链接问题，实现可接受。

2. 项目背景

PxFquery 是一个基于 LINCS 的扰动-功能分析生物信息学工作流，核心能力包括正向查询（从扰动和生物背景推导功能响应）和反向查询（从功能目标和生物背景推导候选扰动）。M1 里程碑的目标是交付一个可运行的反向查询核心实现。T-049 的初始实现在执行中因 execute_config_mismatch 失败，T-060 作为修复替换完成执行，但其交付验收被标记为 red_return（原因是包代码为符号链接而非独立副本）。T-051 作为独立验证门，不负责修复 T-060，而是对被测实现进行严格的功能正确性验证，确保 M1 的反向查询能力在功能层面是可用的、可重复的，并且与合同行为一致。

3. 核心结果

验证覆盖了正向演示、五种错误/无命中情况、排名可重复性、CLI 接口共四个维度，总计 42 项检查全部通过。正向演示以 HALLMARK_APOPTOSIS 为激活程序、HALLMARK_MYC_TARGETS_V1 为抑制程序、A549 为细胞系、top_n=3 执行反向查询，返回的三个候选（THTPA、SCD、TP53，均为 A549 背景）及余弦相似度值与参考完全一致（1.0、0.999959、0.999541）。排名方法为余弦相似度，目标向量构造为激活 +1 与抑制 -1，排序键顺序（相似度降序、cmap_name 升序、cell_iname 升序、sig_id 升序）与参考匹配。五种错误情况（NoMatrixLoaded、ProgramNotFound、ContextNotFound、LowConfidenceResult、空目标无命中）均返回了预期的错误类型与上下文信息。CLI 的 info 与 reverse 命令退出码为 0，error 命令退出码为 1，输出格式正确。包版本为 0.1.0，加载器为 M1FixtureLoader，夹具为 xpr 矩阵 15×9。

4. 项目价值

本次验证确认了 M1 反向查询实现的功能完整性，为 PxFquery 项目的反向查询核心能力提供了独立的、可审计的通过证据。42/42 的通过率意味着下游任务（如算法审查、扩展验证或用户面集成）可以此为基础开展工作，无需重新验证基础功能。验证过程中产生的结构化报告（D-001）和自动化脚本（D-007）可直接复用于回归测试或更广泛的验证场景。对于项目经理而言，本验证结果表明 M1 反向查询的功能层已达到合同要求的技术门槛，剩下的符号链接结构问题不构成功能层面的风险，但应在后续任务中予以规范化修复。

6. 后续使用方式

下游任务（如 T-052 算法审查，或 M2 用户界面集成）可以直接使用 D-001 作为反向查询实现已通过合同验证的主要依据。如果需要扩展验证范围——例如测试更多程序组合、更多细胞系、完整的 10 名候选排序——可以将 D-007 验证脚本作为模板，新增测试用例后复用现有的 M1FixtureLoader 加载管线。包代码的符号链接问题（指向 T-044 而非独立副本）应在后续的包规范化任务中解决，但在功能层面没有影响，不阻塞下游依赖。验证报告 JSON 可直接解析用于程序化审计。

7. 边界与风险

本验证存在三个已知边界。第一，排名对比仅验证了 top-3（匹配协议参数 top_n=3），参考 CSV 中共有 10 名候选，其余 7 名的排序正确性未被检查。第二，验证所使用的夹具为合成数据（15 行 × 9 列的 xpr 矩阵），并非真实生物学扰动实验数据，验证结论仅限于代码功能正确性与行为可重复性，不代表算法在真实数据上的生物学准确性。第三，包代码是一个指向 T-044 的符号链接，如果 T-044 的代码在未来被修改或移动，当前验证的通过结论可能不再有效；这一风险已被记录为追溯性观察，建议在后续任务中将包代码独立化以消除此隐患。
