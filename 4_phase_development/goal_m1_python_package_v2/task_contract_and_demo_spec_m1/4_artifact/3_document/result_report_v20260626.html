2. 项目背景

PxFquery 是一个以 LINCS 数据为基础、面向扰动-功能分析的生物信息学工具。它的核心查询方向有两个：正向查询（从扰动和生物上下文到功能响应）和反向查询（从功能目标和生物上下文到候选扰动）。在进入 M1 包的构建之前，项目需要一个明确的最小可行契约来约束第一个可工作版本的边界——既不包含自然语言解析器、也不包含 LLM 摘要、也不包含代理检索或模糊匹配。T-042 正是在这个位置切入，利用已经审核的 T-007（开发状态消化）和 T-013（MVP 能力审查）成果，将 M1 要做的事情精确锁定到一份可执行的 YAML 契约中。

3. 核心结果
