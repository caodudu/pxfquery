4. 关键判断与证据

在契约撰写过程中遇到了几个需要明确决策的设计点。首先，function_index.json 在迁移后的查询索引中缺失，但该索引不被视为 M1 契约的阻塞项——契约声明 pert2func 和 func2pert 直接操作 h5ad 功能评分矩阵，而 function_index.json 的缺失被记录为 T-048/T-049 必须解决的实现差距。其次，无命中行为被定义为结构化 JSON 错误对象而非异常，所有错误类型（PerturbationNotFound、ContextNotFound、ProgramNotFound、NoMatrixLoaded 等）都带有标识性字段（如 perturbation 名称、cell_line、matrix_type），以便下游代码可以直接解析错误内容。第三，低置信度检测未在契约中硬编码阈值，而是将其作为验证需求声明——M1 实现任务应定义一个阈值（例如 max(|similarity|) < 0.05）。第四，反向查询数值警告被接受为 reverse_result 的 warnings 字段中的可选信息，但实现必须保证所有 top_candidates 的 similarity 值是有限的（非 NaN、非 inf）。
