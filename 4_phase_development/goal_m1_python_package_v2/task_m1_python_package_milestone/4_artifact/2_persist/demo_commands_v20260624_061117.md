## Forward Query (Perturbation → Function)
```bash
pxfquery forward \
  --perturbation EGFR \
  --cell-line A549 \
  --manifest <manifest_path> \
  --fixture-root <fixture_root_path>
```
- Output: `found: true`, `perturbation: "EGFR"`, `cell_line: "A549"`
- `top_activated`: HALLMARK_ADIPOGENESIS (4.03), HALLMARK_APOPTOSIS (2.47), HALLMARK_P53_PATHWAY (1.25), HALLMARK_TNFA_SIGNALING_VIA_NFKB (0.84)
- `top_suppressed`: MP40 PDAC-related (-6.68), HALLMARK_E2F_TARGETS (-6.64), MP39 Metal-response (-0.51)

## Reverse Query (Function → Perturbation)
```bash
pxfquery reverse \
  --activate HALLMARK_APOPTOSIS \
  --suppress HALLMARK_MYC_TARGETS_V1 \
  --cell-line A549 \
  --manifest <manifest_path> \
  --fixture-root <fixture_root_path>
```

## Python API
```python
import pxfquery
from pxfquery.data.m1_loader import M1FixtureLoader

loader = M1FixtureLoader(manifest_path, fixture_root)
xpr = loader.load_matrix("xpr")

# Forward query
from pxfquery.query.forward import forward_query
result = forward_query("EGFR", "A549", xpr)

# Reverse query
from pxfquery.query.reverse import reverse_query
result = reverse_query(
    activate=["HALLMARK_APOPTOSIS"],
    suppress=["HALLMARK_MYC_TARGETS_V1"],
    cell_line="A549",
    xpr_matrix=xpr
)
```
