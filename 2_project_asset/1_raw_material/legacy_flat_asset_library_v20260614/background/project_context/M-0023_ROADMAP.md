# 路线图

## 总原则

当前目标不是把 PxFquery 做成高标准大工具论文，而是先理解 Genes 的真实接收生态，再把现有资产裁剪成“刚好够、风险可控、工作量最小”的投稿方案。

## 阶段 A：彻底理解 Genes

目标：建立 Genes 快速投稿的现实标准，纠正常见误区。

输出位置：

- `10_phase_A_understand_genes/references/`
- `10_phase_A_understand_genes/analysis/`

阶段产物：

- Genes 投稿现实标准。
- Genes 快速稿件模式。
- 不要过度建设清单。
- 阶段 B 的判断标准。

## 阶段 B：PxFquery 与 Genes 匹配

目标：第二阶段才系统整理 PxFquery，判断它应该被包装成什么。

输出位置：

- `20_phase_B_position_pxfquery/code/pxfquery/`
- `20_phase_B_position_pxfquery/positioning/`
- `20_phase_B_position_pxfquery/extraction_plan/`

阶段产物：

- PxFquery 投稿定位。
- 最小可投稿结果包定义。
- 砍掉的功能清单。
- 从归档提取代码/数据/报告的计划。

## 阶段 C：最小结果闭环

目标：只补 Genes 需要的东西，不追求工具完美。

输出位置：

- `30_phase_C_minimal_results/execution/`
- `30_phase_C_minimal_results/results/`
- `30_phase_C_minimal_results/figures/`
- `30_phase_C_minimal_results/tables/`

阶段产物：

- Figures plan。
- Tables plan。
- Result checklist。
- Execution tasks。

## 阶段 D：写作与投稿包装

目标：按 Genes 的接受生态写，不按顶刊叙事或完整工具论文叙事写。

输出位置：

- `40_phase_D_submission/manuscript/`
- `40_phase_D_submission/figures_final/`
- `40_phase_D_submission/supplementary/`
- `40_phase_D_submission/cover_letter/`
- `40_phase_D_submission/submission/`

阶段产物：

- Manuscript outline。
- Section writing prompts。
- Cover letter angle。
- Submission checklist。
