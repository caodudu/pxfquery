## 2. 介绍
LiteLLM 是一个基于 OpenAI SDK 的扩展与模仿工具，
它在 OpenAI API 的基础上进行了优化和拓展，目的是让开发者更方便地使用多个语言模型（不仅仅是 OpenAI 的 GPT 系列），并提供了一些额外的功能和改进。
LiteLLM 基于 OpenAI 的 API，并兼容 OpenAI 的大部分功能，基本上是对 OpenAI SDK 的扩展和包装。它也使用类似的接口来调用语言模型的能力，例如 completion、chat 和 embedding 等 API。



你的代码 (OpenAI 格式)
    ↓
LiteLLM 翻译层
    ↓
├─→ OpenAI API      (直接透传)
├─→ Anthropic API   (转换成 Claude 格式)
├─→ Google API      (转换成 Gemini 格式)
├─→ 本地 Ollama     (转换成本地格式)
└─→ 100+ 其他模型



关键区别
项目	OpenAI SDK	LiteLLM
模型名	deepseek-ai/DeepSeek-V3.2	siliconflow/deepseek-ai/DeepSeek-V3.2
client 对象	需要先创建 client = OpenAI(...)	直接调用 completion(...)
参数位置	通过 client 构造函数传 base_url	在 completion() 里传

### 3.2 标准模板
```python
import os
from litellm import completion

api_key = os.getenv("SILICONFLOW_API_KEY")

response = completion(
    model="deepseek-ai/DeepSeek-V3.2",  # 加上 provider 前缀
    messages=[
        {"role": "system", "content": "你是一个有用的助手"},
        {"role": "user", "content": "你好，请介绍一下你自己"}
    ],
    api_key=api_key,
    base_url="https://api.siliconflow.cn/",
    temperature=0.7,
    max_tokens=400,
    
    # LiteLLM 也支持 extra_body 传递自定义参数
    extra_body={
        "enable_thinking": False,
        "thinking_budget": 4096
    }
)

# 打印输出
print(response.choices[0].message.content)

# 打印推理内容（如果有）
if hasattr(response.choices[0].message, 'reasoning_content'):
    print(response.choices[0].message.reasoning_content)
```
