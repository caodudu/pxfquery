# 2. FastAPI
## 2.1 介绍
https://docs.apiyi.com/wiki/tools/fastapi
FastAPI 是一个现代、快速（高性能）的 Web 框架，用于构建 API（应用程序编程接口）。

FastAPI 就是帮助你 创建快速的接口，通过它你可以让其他程序访问你的一些功能，比如 查询或更新数据。

比如：
你有一堆用户信息（名字、邮箱等）。
你想让某个程序可以 快速添加用户 或 查询用户。

用 FastAPI，你可以：
创建一个接口，其他程序能 通过接口添加用户。
创建一个接口，其他程序能 通过接口查找某个用户的资料。



FastAPI 就是帮你 快速搭建 这些 API 接口，让你和其他系统或用户通过网络交互，获取或操作数据。
具体来说：
API 接口：别人发送一个请求，比如“查询《Python 入门》书籍”，FastAPI 会处理这个请求并返回结果。
自动处理请求和响应：你不需要每次手动去处理请求，FastAPI 会自动帮你处理。
简单暴露功能：你把功能暴露给外部系统或用户，别人通过网络调用，不需要你每次直接操作数据库。
