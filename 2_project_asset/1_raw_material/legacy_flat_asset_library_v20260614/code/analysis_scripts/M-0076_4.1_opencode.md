## 3.2 基本命令
```shell
/agents
/connect
/editor
/exit
/help
/init

/new
/review
```

### 3.2.1 首次使用：初始化项目
```bash
cd /path/to/your/project
opencode
```
进入 OpenCode 后，第一件事：

```bash
/init
```
/init 的作用2022：

分析你的项目结构
创建 .opencode/ 配置目录
生成 AGENTS.md 文件（定义 AI 助手的行为和权限）
设置项目上下文，让 AI 更了解你的代码库


### 3.2.2 /agents - 管理 AI 代理
查看和切换不同的 AI agents（代理）23
每个 agent 可以有不同的系统提示词和工具配置
你可以创建自定义 agent 来完成特定任务
```bash
/agents           # 列出所有可用的 agents
/agents list      # 同上
```


### 3.2.3 /connect - 连接外部服务
连接到 AI 模型提供商（如 Claude、OpenAI、Gemini 等）
配置 API keys
管理连接状态
```bash
/connect          # 查看当前连接状态
```

### 3.2.4 /editor - 打开编辑器
在 OpenCode 内部打开文本编辑器
用于编辑配置文件、查看代码等
类似 vim 的操作界面


### 3.2.5 /models - 管理 AI 模型
查看和切换可用的 AI 模型10
不同模型有不同的能力和成本
常见模型：Claude-3.5-Sonnet, GPT-4, Gemini Pro 等
```bash
/models           # 列出所有配置的模型
/models switch    # 切换模型
```

### 3.2.6 /mcps - MCP 服务器管理
MCP (Model Context Protocol)：一种标准协议，让 AI 访问外部工具和数据2830
管理 MCP 服务器连接
比如连接数据库、API、文件系统等
```bash
/mcps             # 列出 MCP 服务器
```

### 3.2.7 /new - 开始新对话
清除当前对话历史
开始一个全新的上下文
类似"重置对话"
```bash
/new              # 开始新的对话会话
```

### 3.2.8 /review - 代码审查
让 AI 审查你的代码
检查代码质量、潜在 bug、最佳实践等
可以针对特定文件或整个项目
```bash
/review [文件路径]     # 审查特定文件
/review               # 审查当前上下文中的代码
```

### 3.2.9 /exit - 退出 OpenCode
退出程序
或者用快捷键：Ctrl+C 或 Ctrl+D

### 3.2.10 /help - 帮助文档
查看所有可用命令
查看特定命令的详细说明
bash
/help             # 显示所有命令
/help init        # 查看 /init 命令的详细说明

## 3.4 模式
OpenCode 内置两种 Agent，可用 Tab 键快速切换：

build - 默认模式，具备完整权限，适合开发工作
plan - 只读模式，适合代码分析与探索
默认拒绝修改文件
运行 bash 命令前会询问
便于探索未知代码库或规划改动
另外还包含一个 general 子 Agent，用于复杂搜索和多步任务，内部使用，也可在消息中输入 @general 调用。
