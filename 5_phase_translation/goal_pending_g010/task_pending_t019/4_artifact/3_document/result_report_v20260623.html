子任务 1：GitHub Pages 用于学术论文配套网站

结论：完全可行，已被大量期刊论文采用

GitHub Pages（*.github.io）是学术界广泛接受的论文配套网站托管平台，包括 MDPI Genes、Bioinformatics、Nucleic Acids Research 等期刊均不限制使用。期刊核心关注的是论文的同行评审质量和数据可访问性，而非托管服务商。

真实论文案例：

  • BioBuntu — 开源生物信息平台，发布在 BioTech (MDPI, 2025)。网站：biobuntu.github.io
  • EDGE — 微生物基因组分析工具，发表在 Nucleic Acids Research Web Server Issue。网站：lanl-bioinformatics.github.io/EDGE/
  • Epiviz File Server — 基因组交互式可视化工具，发表在 Bioinformatics (Oxford, 2020)。网站：epiviz.github.io

免费额度：GitHub Pages 免费，无强制收费。公共仓库即可使用，支持自定义域名和自动 HTTPS。

子任务 2：GitHub Pages 集成 LLM API

结论：纯静态站可以直接调 LLM API，但有约束

方案后端需求安全性延迟
纯前端 JS 直接调 API无⚠ 密钥暴露客户端直接
+ Cloudflare Workers 代理免费 Workers 层密钥在 Worker加一跳
+ 完整后端（PxFquery 全部功能）需要服务器安全可接受

PxFquery 分析：纯前端方案可展示预计算结果和 LLM 对话示例；但完整矩阵查询（h5ad 加载、索引检索）必须有后端。建议论文初期用纯静态站做展示，完整分析功能放在 GitHub 仓库中供用户本地运行。

子任务 3：生信网站完整部署流程

全流程概览

  1. 准备：前端代码（HTML/React/Vue）+ 后端代码（Python Flask/FastAPI）+ 数据文件（h5ad/JSON）→ GitHub 仓库
  2. 域名：免费 username.github.io 或自定义域名 ¥50-150/年
  3. 部署：静态页 → GitHub Pages；有后端 → Render/Railway/Fly.io/阿里云
  4. 分析型站特点：需要 Python 运行时、大文件存储、异步任务（Serverless 超时 10-30s 不适合长计算）
  5. 维护：UptimeRobot 免费监控、GitHub Actions 自动 CI/CD

详细步骤见 4_artifact/2_persist/bioinfo_website_deployment_guide.md

综合建议（对 PxFquery）

推荐起步方案

第一阶段（论文提交前）：GitHub Pages 免费静态站 + 论文摘要、方法介绍、功能截图、文档链接。零成本，无后顾之忧。

第二阶段（审稿中或发表后）：在 GitHub Pages 上增加一个交互式案例演示页（纯前端 JS + Cloudflare Workers + LLM API 代理），展示一个 PxFquery 正向/反向查询的实时示例。

第三阶段（如需完整在线分析功能）：使用 Render 免费层或 Railway $5/月 部署 Python 后端，支持用户上传简化的表达矩阵并运行查询。

底层计算：核心矩阵计算和索引检索留在 Python 包中，用户可通过 pip install 和 Jupyter notebook 本地运行。网站上展示结果截图和预计算案例。
