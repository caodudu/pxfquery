# 小型生物信息网站低成本全栈托管方案对比

> 调研日期：2026-06 价格信息为近似值，来源为各平台公开定价页面，建议部署前二次核对。

本对比面向"小规模生物信息查询网站"的部署需求：通常一个静态前端 + 可选 Python 后端 + 几百 MB 至几 GB 的 h5ad / CSV 数据，需要在 1-2 年的项目周期内保持可访问，但不希望承担高额云费用。下面列出 5 个真实可行的方案。

---

## 方案 A：纯 GitHub Pages（免费）

- **价格**：$0 / 年（GitHub 免费账户即包含）
- **适合**：纯静态展示站（文字、图表、文档、HTML 报告）
- **不支持**：实时计算、Python 后端、服务端读写
- **资源限制**：仓库建议 ≤ 1 GB（软上限），月带宽 100 GB（GitHub Pages 公开限额）
- **数据托管**：大于 50 MB 的 h5ad 不进仓库，改用 GitHub Releases 当 CDN（每文件 ≤ 2 GB），或外链到 Zenodo / Figshare
- **URL 示例**：`https://yourname.github.io/scrna-query/`
- **优点**：零成本、自动 HTTPS、与 Git 版本绑定、学术界接受度高（NAR Web Server Issue、MDPI Genes 均接受 `.github.io` 作为配套网站 URL）
- **缺点**：纯 static，无法做服务端运算；若查询需要实时计算，需在前端用 WebAssembly 或把数据预生成好

---

## 方案 B：GitHub Pages + Vercel Functions 混合

- **前端托管**：GitHub Pages $0
- **后端**：Vercel Hobby（个人免费层）$0
- **Serverless Functions 免费额度**：100 GB-Hours / 月，超出后约 $0.18 / GB-Hr（按 Vercel 公开 Pricing 页面，2026-06 查询）
- **适合**：静态前端 + 偶尔被调用的 API / Python 函数（如对上传的基因列表做 GO 富集分析）
- **Edge Functions / Cron Jobs**：Hobby 层提供有限的 Cron 任务（每天 2 次）和 Edge Middleware
- **数据**：可将中等体积 CSV / JSON 放进 Vercel 项目（构建产物上限通常与 Hobby 配额匹配），h5ad 大文件仍建议外链
- **URL 示例**：`https://yourname-bioinfo.vercel.app/`，可独立绑定 `api.yourname.com` 作为函数端点
- **优点**：Git 推送即部署、自动预览 URL、Python Node 都支持、函数冷启动 < 1s
- **缺点**：函数无状态，长任务（> 60s，免费层 Hobby 单函数最长 10s，Pro 层最长 60s）需要拆分；冷启动在偶发流量下可能有 1-3 秒延迟

---

## 方案 C：Render 免费层 + 自定义 Web 服务

- **价格**：$0 / 月（Free Tier）
- **静态站**：免费托管静态站点，自动 HTTPS
- **Web Service 免费层**：750 小时 / 月，足以支撑单实例运行
- **关键限制**：15 分钟无活动后实例进入休眠，下次访问有约 30 秒冷启动
- **适合**：Python Flask / FastAPI 小应用、允许偶发首屏延迟的演示站
- **不支持**：需要持续运行的后台任务（休眠期间进程被挂起）
- **数据**：可挂载 Persistent Disk（免费层不可用，需升级到 Starter $7/月起）；小数据集可以打进 Docker 镜像，但镜像构建慢、不灵活
- **URL 示例**：`https://scrna-query.onrender.com/`
- **优点**：原生支持 Python + Dockerfile、零成本、绑定自定义域名免费
- **缺点**：免费层必须休眠，交互体验上对"点开就用"的用户不友好；2024 年起 Render 调整了 Free Tier 对个人项目的策略，使用前请查官网最新条款

---

## 方案 D：阿里云轻量应用服务器（国内访问）

- **价格**：年付约 ¥600 - ¥1500（基础配置 2 核 2 GB内存 / 50 GB SSD / 4 Mbps 带宽；2026-06 阿里云轻量应用服务器公开活动价，新用户首年常有折扣）
- **适合**：需要持续运行的 Python 服务、需要本地托管 GB 级 h5ad 数据、需要国内低延迟访问
- **合规要求**：使用 `.cn` / `.com.cn` 域名必须 ICP 备案（一般 7-20 个工作日）；非 `.cn` 域名可不备案，但服务器仍需选择有公网 IP 的境外或香港节点
- **操作系统**：CentOS / Ubuntu / Debian 自选，可装 Docker
- **URL 示例**：`http://your-server-ip:8000/` 或备案后绑 `bioinfo-lab.cn`
- **优点**：性能稳定、国内下载 h5ad 快、SSH 完全可控、可挂载大硬盘
- **缺点**：需运维（系统更新、安全加固、nginx 配置）；备案流程麻烦；每年有最低续费成本

---

## 方案 E：Railway 付费层

- **价格**：按用量计费，Trial 层赠送 $5 / 月（需绑定信用卡，过期后不再赠送）；常规 Hobby Plan 起步 $5 / 月含 $5 用量（约 36 元 / 月，按 2026-06 汇率）
- **超出后**：按 vCPU · GB · 内存 · 流量单价计费，公开 Pricing 页面给出参考单价
- **适合**：需要长时间运行的 Python 后端（Flask / FastAPI / Django），小数据集可以直接放进容器
- **URL 示例**：`https://scrna-query.up.railway.app/`，可绑自定义域名
- **优点**：GitHub 仓库直连、自动部署、Postgres / Redis 即插即用、无休眠
- **缺点**：Trial 的 $5 用量对中型数据集 + 持续流量容易用完，需切到付费 $5 起 + 用量计费；长时间持续高负载最终账单可能超出"低成本"边界

## 5 方案横向对比表

| 方案 | 起步年费 | Python 后端 | 大文件托管（GB 级 h5ad） | 适用规模 | 备注 |
|------|----------|------------|---------------------------|----------|------|
| **A. GitHub Pages** ⭐ | **$0** | ❌（仅静态） | ⚠️ 用 Releases / 外链 | 个人作品集、纯展示 | **最符合"免费优先"** |
| **B. Pages + Vercel Functions** ⭐ | **$0**（Hobby） | ✅ Serverless | ⚠️ 小数据可内置，大文件外链 | 偶发 API 调用 | 冷启动 < 1s |
| **C. Render Free** | **$0** | ✅ Web Service | ⚠️ 免费层无持久磁盘 | 演示型小应用 | 15 分钟无活动即休眠 |
| **D. 阿里云轻量** | **≈ ¥600-1500** | ✅ 完全可控 | ✅ 本地 SSD | 国内访问、稳定运行 | 需备案、自运维 |
| **E. Railway** | **≈ ¥432 / 年（$36 / yr）起 + 用量** | ✅ 持续运行 | ✅ 容器内可挂载 | 中等规模、长期运行 | 无休眠、按用量计 |

> 表中 ⭐ 标记为完全符合"免费优先"偏好的方案。如果项目只在论文投稿 / 学术分享阶段，**首选 A**；一旦加入后端计算（如 GO 富集、差异表达在线分析），**首选 B** 或 **C**。

---

## 推荐决策路径

1. **仅展示结果（论文配套网站、可重现报告）** → 方案 A（GitHub Pages），零成本、学术圈接受度最高。
2. **需要一点点后端计算（基因列表 → 富集结果）** → 方案 B（Pages + Vercel Functions），把 h5ad 放 Releases / Zenodo，函数每次重新读。
3. **需要常驻 Python 服务但可接受冷启动** → 方案 C（Render Free）。
4. **国内用户为主、需要大文件本地化、稳定 SLA** → 方案 D（阿里云轻量），接受 ¥600+ / 年的运维成本。
5. **需要 7×24 在线且不愿运维、又愿意每月花一杯咖啡钱** → 方案 E（Railway $5 起）。

---

## 几个跨方案的省钱小贴士

- **大文件永远外链**：h5ad 几百 MB 放进任何一家云的对象存储都比放在仓库 / 容器内便宜得多。Zenodo（科研免费）一个 DOI 永久可访问。
- **先用免费层验证流量**：Vercel / Render / Railway 都提供日志面板，部署后看一周真实访问量，再决定要不要付费升级。
- **混合架构**：GitHub Pages 发主体内容 + Vercel Functions 跑轻计算 + Zenodo 托管数据，是"零成本可持续"的最优组合。
- **国内备案**：如果项目用户主要在国内但暂时不想备案 7-20 天，可用 Cloudflare 代理境外节点；或者直接用香港 / 新加坡节点的轻量服务器免备案。
